# Pharos Staking workbench releases

Signed update packages for the Pharos Staking workbench in Anvita Mate.

- `test-latest` / `prod-latest`: `latest.json`, the signed manifest each channel checks.
- `<channel>-v<version>`: the `.ambundle` for that version.

Published by `npm run release:test` / `npm run release:prod` in the source repo.
